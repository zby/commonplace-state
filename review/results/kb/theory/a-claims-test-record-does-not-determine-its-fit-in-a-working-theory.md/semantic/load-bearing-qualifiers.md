# Review

## Summary

Qualifiers in the title, description and opening, and the work each one does:

- **"in a working theory"** (title). This qualifier is load-bearing. Fit is defined relative to a theory's problem, scope and other retained claims. Without a theory there is nothing for fit to be relative to.
- **"independent"** and **"so far"** (description and opening). Both are load-bearing. "Independent" separates tests from agreement that only reflects the theory's own assumptions, which is the argument of the "Fit is not an independent test" section. "So far" carries the dated, fallibilist reading of a test record that the Popper section relies on.
- **"only where the claim could have failed"** (description). This is the criterion that decides when use in the theory counts as a test. Deleting it would make the note claim that fit is never a test, which the body explicitly denies.
- **"for a universal claim"** (opening). This is load-bearing. A singular claim can be decided, so removing the qualifier would make the sentence false.

None of these qualifiers narrows the central claim beyond what the argument needs. The argument about test records and fit is not tied to any particular kind of system, and the title does not tie it to one either.
