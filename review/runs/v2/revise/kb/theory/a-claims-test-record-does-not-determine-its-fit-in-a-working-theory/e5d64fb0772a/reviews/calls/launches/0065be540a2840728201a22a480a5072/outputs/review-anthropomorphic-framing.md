# Review

The note makes no claims about model cognition. Its agents are "a system", "the theory" and "logic". "A working theory is the set of claims a system currently uses to explain, predict, search and modify" uses ordinary system metonymy. "Logic says only that the claims cannot all be kept" is conventional shorthand for what follows logically. "Has earned a new independent test" is figurative, but it gives no mental property to a model, so this gate does not own it. No verbs such as "knows", "understands" or "believes" are applied to models.
