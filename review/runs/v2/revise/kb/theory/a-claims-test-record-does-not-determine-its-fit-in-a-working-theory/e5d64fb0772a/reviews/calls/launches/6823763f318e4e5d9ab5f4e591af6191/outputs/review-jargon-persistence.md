# Review

## Summary

The note's recurring terms are "working theory", "test record", "fit" and "independent test". Each is defined in the opening list, and each is close enough to plain English that later uses read correctly without scrolling back. A "test record" is a record of tests survived. "Fit" is used in sentences whose context restates what it concerns, such as "fit to its problem" or "retain it in this theory". The definitions only make the senses more precise.

None of these is borrowed framework vocabulary that has a plainer equivalent the note should switch to. They are the note's own subject terms, and replacing them would lose the distinctions the note exists to draw. The Popper terms ("corroborated", "severe test") each appear once or twice, so they do not persist in the way this gate checks for.
