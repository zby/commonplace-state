# Review

The note attributes no mental properties to models. Its agent is a generic
"reader", whose choosing, inspecting and recovering a view are literal actions
of whoever navigates the knowledge base. It makes no claims about model
internals.

Wording such as "Search supplies another broad entry route", "Link context
preserves bearings" and "Resolution-switching helps a reader assemble those
views" is conventional metonymy for software and document mechanisms. The
gate's exception covers this usage. The note does not use `knows`,
`understands`, `believes` or a similar cognitive verb for a system.
