# Review

## Summary

The note names only one proper noun: "Commonplace", in the heading of the
section that lists its mechanisms. The note never says what Commonplace is.
The listed mechanisms (titles, descriptions, indexes, link context, progressive
disclosure) imply a knowledge-base system. Even so, a first-time reader must
infer from those examples what kind of thing the name refers to, and whether
it is the host KB. A brief inline identification would resolve this. The note
names no other systems, tools, people or organizations.
