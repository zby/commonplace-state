# Review

## Summary

The note keeps its conceptual roles distinct. It stipulates its term openly: "This note calls movement between those views **resolution-switching**". It fixes the meaning of the borrowed word "resolution" as "the scope and detail exposed by a view, not an intrinsic abstraction rank assigned to an artifact." It then names the evaluative criterion separately as "resolution-switching fluidity." The term, the concept and the criterion applied to a knowledge base are therefore not blurred.

The passages that import material from linked notes state a clear relation. Title-as-claim "supports traversal", the search and link-following routes "have different metadata requirements", and pointer types "trade off" their axes. In each case the linked account is cited for its own claim, and this note applies that claim. Whether "the navigational value of encoding link strength" is supported by the target is a grounding question, not a role conflation, because the attribution itself is unambiguous. The Boundaries section separates resolution-switching from addressability grain, pointer accuracy and retrieval recall as different properties. It does not identify them with one another.

No passage permits two materially different role assignments.
