- "an experiment identifies only the contrast it actually runs" → this is used for the experience-link manipulation, which is consistent with the target.

One identity claim fails: the antecedence sentence. The note's prior-declaration condition is not the same condition as the target's antecedence. Instead, it adds a temporal requirement on top of it.
