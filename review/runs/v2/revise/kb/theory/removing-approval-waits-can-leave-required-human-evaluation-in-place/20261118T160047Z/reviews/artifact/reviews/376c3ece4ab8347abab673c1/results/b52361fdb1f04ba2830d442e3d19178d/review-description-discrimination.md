## Summary

The description does more than restate the title. The title says removing approval waits can leave required evaluation in place. The description adds the mechanism behind that: removing a wait is a different change from automating or retiring a specified evaluation task. It names those two alternatives, "automating" and "retiring". It also adds scope: optional assessment need not be part of either change. That third category, optional assessment, does not appear in the title. It helps an agent tell this note apart from nearby notes about routine approvals or before-and-after comparisons of a system.
