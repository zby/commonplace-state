# Review

## Summary

The core claim is that a fixed instruction to consult past incidents can absorb new lessons only if the reviewer can tell when an earlier failure applies to a new case. All three paragraphs support it. The first states the gap between "where to look" and "which failure bears". The second gives a worked case, and the third restates the test as a distinction the review must draw. No secondary material outgrows the core. The example paragraph is the longest, but it serves the claim rather than competing with it. The only thin spot is the applicability condition itself, recorded as information.
