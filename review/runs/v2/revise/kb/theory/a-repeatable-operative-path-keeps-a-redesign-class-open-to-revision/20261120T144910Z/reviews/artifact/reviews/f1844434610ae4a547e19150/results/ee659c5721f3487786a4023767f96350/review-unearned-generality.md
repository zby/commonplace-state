# Review for unearned generality

Substituting editable agent code for redesign class would discard the human review and deployment route and the redesign of verification through a mark, schema, and validator. The argument operates on causal functions shared by those cases. Its general wording rules out treating an installed validator change as repeatable if the next challenge cannot reach review and installation, just as it rules out that inference for installed agent code whose successor blocks further admitted changes.
