# Review of framework decoration

The six checks let the reader identify the missing function in a concrete
case. Representation identifies where a proposed redesign can take effect,
determination asks whether evidence can shape the proposal, and admission
identifies what gives it authority to replace the incumbent. The evidence
inventory then uses the distinction between installation and dependence to
classify a result that is installed and loaded without demonstrated influence
on later behavior. Reapplying the first five checks to the successor explains
why a prompt rewrite can take effect while closing the route that admitted it.
A one-sentence description of the path would lose those diagnostic distinctions.
