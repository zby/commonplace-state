# Review

## Summary

"A note is an atomic step relative to the check that reads it" is a proposition with a subject and a predicate, and it can be true or false. It would be false, for example, if atomicity were a property of the note alone. It is not a topic label, category name or artifact name, so it keeps the promise made by the `title-as-claim` trait.
