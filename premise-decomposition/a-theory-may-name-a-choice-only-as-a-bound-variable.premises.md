# Premise decomposition: A theoretical artifact must preserve the scope of each named system choice

**Note:** kb/notes/a-theory-may-name-a-choice-only-as-a-bound-variable.md
**Register:** claim
**Central commitment (one sentence):** A theoretical artifact preserves the scope of a proposition that names a system choice only when its intended consumers are guaranteed enough permitted context to recover both the choice's referent and its role in that proposition, although that context need not take the form of a sentence-local or literal quantifier.

## Premises and counterexamples

1. **Every admitted role, including a ranged use, supplies an answer to “which choice does the name denote?” that an intended consumer must recover.** — DOUBTFUL — In “for every admissible router R, latency(R, x) is nonnegative,” R has no single choice as its referent: the binder and domain give the proposition complete scope while R receives different values under different variable assignments. If “assignment” means the valuation rule or range rather than an identified selected value, the note needs that distinction; the stated “which choice?” requirement does not express it. — GLOBAL — instance
2. **A theoretical artifact fails to preserve a fixed choice's scope whenever intended consumers cannot recover which design its rigid name denotes, even if they can reidentify that same opaque choice and reason about it.** — DOUBTFUL — A published proof can bind the name S to an immutable blinded commitment, verify that the committed proprietary scheduler is starvation-free, and deliberately withhold the commitment-to-design mapping. Consumers can keep S fixed, verify the proof, and import the bounded conclusion about the same subject without discovering which scheduler design S is. This makes stable reidentification sufficient for the artifact's use while descriptive identification remains unavailable; whether that counts as recovering “which choice” is left unresolved. — GLOBAL — instance
3. **For a proposition whose truth conditions depend on a system choice, referent assignment and propositional role are independent necessary parts of that choice's scope.** — HOLDS — The active hunt considered predicates invariant under every assignment, but in those cases the named value is not doing choice-dependent work. In a dependent case, “for router R” can fix the role while leaving the version unknown, and a registry can identify R while a detached fragment leaves unclear whether R is fixed, ranged, or offered as a witness; no counterexample made either obligation dispensable.
4. **Only context admitted by the interpretation boundary and guaranteed by the consumption boundary can supply a named choice's scope, although that context may lie outside the sentence.** — HOLDS — A quotation detached from its setup was the strongest candidate, but detachment changes the declared consumption unit: whole-note discourse suffices for whole-note consumers, while independently retrieved fragments need their own assembly context. A precise identifier can itself carry an assignment, but an unshipped lookup on which interpretation depends did not provide a counterexample.
5. **Literal quantifier syntax is neither necessary nor sufficient for recovering a named choice's assignment and role.** — HOLDS — Prior discourse can introduce one versioned router and later use its name as a fixed constant without another binder, while “for router R” supplies an explicit fixed-role construction without identifying the router or version; the active hunt therefore found examples supporting both halves rather than a defeater.
6. **Recovering every named choice's assignment and role is sufficient to settle what the containing proposition says, apart from explanation, evidence, and transfer.** — DEFEATED — An artifact can identify R as router version 3 and clearly hold R fixed in “R is faster” while leaving the comparison router, workload, and metric unstated. Assignment and role settle R's scope but do not settle the proposition's truth conditions. Restricting the sufficiency claim to “what the proposition says about that named choice's scope” preserves the central requirement. — LOCAL — instance
7. **Controlled substitution exposes whether a system-specific term denotes a general pattern, an explicitly fixed choice, or an unresolved assignment when co-referring expressions are substitutable.** — DOUBTFUL — Suppose a selected priority queue is locally called “the fast lane.” Replacing it with the co-referring description “the queue configured to drain first” preserves “the fast lane drains first,” but only because the replacement smuggles the selected priority rule into a definite description and turns the claim toward a tautology; it does not show that the local term labels a cross-system pattern. The diagnostic needs an independent constraint on what qualifies as the general description. — LOCAL — instance
8. **A fixed design contributes theory only through a substantive proposition such as explanation or counterfactual compression, and existentially restating its selection is not by itself such a contribution.** — HOLDS — A complete transition table was the strongest candidate because it can support predictions about one fixed design, but when it compresses counterfactual behavior it meets the note's substantive-proposition allowance, and when it merely records outputs it remains description. Likewise, using one selected instance to refute an impossibility claim adds a feasibility proposition beyond the bare selection, so it does not defeat the premise.

## For the human

Look first at premise 1: the note's “which choice?” language fits fixed uses but does not yet say what assignment recovery means for a genuinely ranged variable that has no single referent.
