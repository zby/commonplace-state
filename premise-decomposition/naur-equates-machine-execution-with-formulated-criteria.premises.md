# Premise decomposition: Naur's inexpressibility argument does not by itself make program theory human-only

**Note:** kb/notes/naur-equates-machine-execution-with-formulated-criteria.md
**Register:** claim
**Central commitment (one sentence):** Naur's claim that program theory cannot be reduced to formulated criteria or rules does not by itself prove that only humans can possess program theory, because machine-effective judgment can be fixed without a human-formulated rubric.

## Premises and counterexamples
1. **Universal: Naur's inexpressibility argument, as used by this note, targets the absence of formulable human criteria rather than the impossibility of every formally executable determination.** — DOUBTFUL — Naur's own wording also says the relevant similarity is outside what can be determined by rules and accessible to human theory-holders, so a broad reading can treat rule-determination, not merely human-written rubrics, as the target from the start. — GLOBAL — instance
2. **Universal: A human-formulated rubric and a machine-effective determination are distinct kinds of determination.** — HOLDS — Active hunt found no defeater: a finite architecture-plus-state can fix outputs while failing to present a human-usable list of judgment criteria.
3. **Universal: A learned recognizer can execute a formal decision function without any programmer first writing the criteria that decide each case.** — HOLDS — Active hunt found no defeater: neural recognizers are a concrete case where the runtime computation is formal while the operative similarity function is fitted from examples rather than authored as a rubric.
4. **Universal: The learned-recognizer case defeats the bridge premise when that bridge says programs in general can determine judgments only by applying human-formulated criteria.** — HOLDS — Active hunt found no defeater at the bridge's universal modality: one machine judgment fixed without a human-authored rubric is enough to block the universal bridge.
5. **Universal: The learned-recognizer case is relevant enough to Naur's program-modification judgment to weaken the inference from absent criteria to human-only theory possession.** — DOUBTFUL — A face classifier may compute a similarity classification without explaining, justifying, or mapping program structure to world activity, so it may switch from Naurian theory-possession judgment to a thinner recognition task. — LOCAL — instance
6. **Universal: If the bridge from unformulable criteria to impossible machine judgment is blocked, the note does not need to show that any machine currently possesses a program theory.** — HOLDS — Active hunt found no defeater: the central claim is a non-entailment claim, and the note's scope explicitly leaves current machine or LLM-plus-artifact theory possession unproved.
7. **Universal: Naur's compiler handoff case establishes a bounded transfer failure by the supplied program text, annotations, design discussion, and advice, rather than an in-principle proof that no artifact-plus-interpreter could acquire the theory.** — HOLDS — Active hunt found no defeater: the reported case shows that that successor group and that supplied package failed, while stronger impossibility needs an additional generalization.
8. **Universal: A theory-holder claim for an interpreter-plus-artifact composite must be tested on program-specific acquisition, premise supply, and dispositional reliability.** — DOUBTFUL — A composite could appear to pass these tests through opaque retrieval, memorized local cases, or external supervision without possessing the kind of explainable theory Naur requires, so the tests may be necessary probes but not sufficient discriminators. — LOCAL — instance
9. **Universal: If coherent modification depends on a decision premise the interpreter cannot recover from implementation and general knowledge, some component of the composite must supply that premise.** — HOLDS — Active hunt found no defeater: the premise is analytic for unrecoverable information in a composite system, since the needed content must either be recovered, supplied, or absent.
10. **Universal: Naur's human-binding conclusion may rest on world knowledge or mental-possession premises, but those are additional premises rather than consequences of inexpressibility alone.** — DOUBTFUL — Naur presents world knowledge, human accessibility, and inexpressibility in adjacent parts of the same account, so separating them may be a reconstruction choice rather than a clean textual entailment boundary. — LOCAL — instance

## For the human
Look first at premise 1: the report pressure is on whether the note's narrow "human-formulated rubric" reading is sufficiently explicit to survive Naur's broader "determined by rules" language.
