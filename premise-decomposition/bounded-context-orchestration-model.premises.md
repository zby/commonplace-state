# Premise decomposition: Bounded-context orchestration model

**Note:** kb/notes/bounded-context-orchestration-model.md
**Register:** claim
**Central commitment (one sentence):** A closed-world joint LLM-code workflow with symbolic inter-call execution, explicit resumable transition state, and completed calls can be represented as repeated feasible call selection and explicit state transition, while meaningful strategy comparisons over that representation require stated invariants and an ordering criterion.

## Premises and counterexamples

1. **The singular `select(K) -> C; call(C)` loop represents parallel completed-call workflows that satisfy the opening conditions without changing behavior relevant to strategy comparison.** — DEFEATED — Consider a scheduler that selects two independent ten-minute calls from the same `K`, runs them concurrently, waits at a barrier, and merges their results. The four defined elements make `C` one call specification with one prompt, while the loop invokes `call(C)` once per iteration. Serializing the calls doubles barrier latency, which the note itself names as a comparison dimension; selecting a batch instead changes the type of `C` and the semantics of `call` beyond the stated loop. — GLOBAL — instance
2. **The three opening conditions are sufficient to ensure that the next call selected by the represented system is feasible for its prompt, task, model, and required performance threshold.** — DEFEATED — A fully symbolic scheduler with complete explicit state can deliberately submit a 200,000-token prompt to a model with a 128,000-token hard limit, wait for the completed error result, incorporate it, and retry. It satisfies all three opening conditions but violates the loop's `require feasible(...)` guard, so those conditions do not suffice for the normal form as stated. — LOCAL — instance
3. **When `K` is the complete resumable machine state and every inter-call step is symbolic, execution between completed LLM calls can be absorbed into `select(K)` and `transition(K, C, r)`.** — HOLDS — The hunt tried branches, retries, queues, cached views, phase changes, and nested symbolic loops; each can be encoded by storing the control position and relevant values in `K` and running symbolic computation to the next call site. A counterexample required hidden transition state, independent environmental change, or a result acting before completion, each of which violates an explicit boundary.
4. **Treating each LLM call as atomic is adequate when no partial result influences later scheduling before that call completes.** — HOLDS — Cancellation, token-level routing, and mutually interacting streams defeat atomic treatment, but the note expressly excludes them. Within the completed-call condition, intermediate tokens are not transition-relevant and replacing the call by its completed result preserves the later scheduler decisions.
5. **Explicit `K` can represent all transition-relevant state in the claimed closed-world domain even though no one call receives all of `K`.** — HOLDS — The hunt tried remote mutation, expiring credentials, clocks, and concurrent actors; each makes the environment change independently between observations and is excluded by the note's boundary unless its observed effects are incorporated before selection. For the remaining closed-world cases, source artifacts, control position, retained results, and derived views can remain outside a call and be projected into bounded call specifications as needed.
6. **Material selection and task framing cannot generally be optimized independently because framing can change the performance value of the same selected material.** — HOLDS — Fixed-format extraction supplies cases where framing has little room to vary, but does not establish that such cases dominate adaptive synthesis and conflict-resolution workflows. In those workflows, the requested relation and operation can change whether the same evidence is usable within the call's performance threshold.
7. **A determinate claim that one selection strategy improves on another must identify a preserved comparison basis and an objective, constraint, or ordering relation.** — HOLDS — Pareto comparisons, randomized trials, and qualitative auditability comparisons were tested as counterexamples; each still fixes a workload, semantics, evidence obligation, or other basis and states dimensions or a relation under which the strategies are ordered. Without both, differences can be described but not directed as improvement.
8. **A local strategy comparison must specifically hold relevant semantics or evidence coverage fixed rather than allowing the ordering criterion to price a change in them.** — DOUBTFUL — Two strategies can be compared on the same task distribution by a declared utility or Pareto relation even when one intentionally trades a small decrease in success or evidence coverage for a large latency reduction. The comparison remains determinate because the changed quality is an explicit criterion dimension, so fixed semantics or evidence coverage may be one useful invariant rather than a universal requirement. — LOCAL — instance

## For the human

Look first at premise 1: the prose adds a batch extension, but the defined singular `C` loop cannot preserve parallel latency without changing its own call-specification and call semantics.
