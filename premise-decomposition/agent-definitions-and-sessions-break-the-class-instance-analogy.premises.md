# Premise decomposition: Instantiation alone cannot model agent learning across sessions

**Note:** kb/notes/agent-definitions-and-sessions-break-the-class-instance-analogy.md
**Register:** claim
**Central commitment (one sentence):** The class/instance analogy explains how a durable agent definition supplies a session's starting structure, but cross-session learning additionally requires a governed transformation of that definition and a revisable policy for placing reusable content.

## Premises and counterexamples
1. **Instantiation, considered by itself, maps a durable definition to a run with local state but does not specify a transition from the current durable definition to a revised one.** — HOLDS — Reflective classes, metaclasses, and constructor side effects can mutate shared class state, but each adds a mutation path to the instantiation relation; none shows that creating an instance, without such an added path, models an evidence-responsive revision inherited by later instances.
2. **Agent learning that affects later sessions requires an operative change to retained behavior-determining structure rather than only a transient improvement inside one session.** — HOLDS — A session can improve its current answer through additional reasoning or warm-up without changing anything later sessions consume, but that is a counterexample only to equating within-session improvement with cross-session learning, not to this premise.
3. **Reflection or persistent mutation alone does not establish learning, because the change must be responsive to improvement-relevant evidence and must affect later operation.** — HOLDS — A Smalltalk process can rewrite a method reflectively and a session can append arbitrary text to memory, yet either change can be blind, harmful, or never consumed; the counterexample hunt found no mutation whose mere persistence establishes learning.
4. **Every cross-session learning path requires a candidate write-back and a selection result that decides whether later sessions receive it.** — DEFEATED — In online gradient descent, an observed loss can directly determine a weight update that is automatically retained and used by later runs; there is no separately rejectable candidate or adoption decision, yet the changed weights are an evidence-responsive operative change. — GLOBAL
5. **The evidence driving cross-session learning must be experience produced by a prior agent session.** — DEFEATED — A training pipeline inside the declared system boundary can ingest newly labeled environmental data between sessions and directly update the deployed model before the next session; the later session inherits learned structure even though no earlier agent session produced the evidence. — GLOBAL
6. **For reusable content, placement among session-local derivation, retained retrieval, always-loaded context, and stronger enforcement is both behaviorally consequential and revisable.** — HOLDS — A repository map or checklist can concretely be recomputed, retrieved, inserted into every starting context, or encoded in tooling, with different rediscovery, context, staleness, and maintenance costs; inherently run-specific inputs do not defeat the premise's restriction to reusable content.
7. **A fixed class/instance shorthand tends to conceal the fact that reusable content placement is a policy choice.** — DOUBTFUL — An object-oriented design can explicitly represent per-instance state, class-level defaults, lazy external resources, configuration loaders, and reflective migration between them, so the analogy need not conceal placement when those mechanisms are included; the claim needs to remain limited to the stated closed-world shorthand rather than class/instance modeling generally. — LOCAL
8. **In an LLM-style context-mediated runtime, material loaded during a session can acquire episode-scoped behavioral authority without becoming retained system-definition material.** — HOLDS — A retrieved instruction or project rule can alter subsequent model actions through the context channel and then disappear at session end; typed-state runtimes that cannot interpret session data fall outside the note's explicit transfer condition rather than defeating the scoped premise.
9. **Repeated reconstruction of substantially the same useful warm-up material is evidence for considering, but not automatically performing, promotion into reusable structure.** — HOLDS — Repeated exploration may still be cheaper, fresher, or more task-sensitive than retention, but those cases argue against promotion after evaluation, not against treating recurrence as a candidate signal.
10. **A stable session boundary can be assumed when modeling the transformation from one session-start definition to the next.** — DOUBTFUL — Compaction, resumable threads, nested sub-agents, and shared memory can produce several defensible episode boundaries with different answers about what was retained versus merely carried forward; declaring one boundary rescues the mapping, but the resulting claim is boundary-relative. — LOCAL

## For the human
Look first at premise 4: direct evidence-driven updates provide cross-session learning without the proposal-and-selection architecture that the note currently makes universal.
