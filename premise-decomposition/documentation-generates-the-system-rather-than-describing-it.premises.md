# Premise decomposition: Attempted recovery identifies informational gaps, not provenance or authority

**Note:** kb/notes/documentation-generates-the-system-rather-than-describing-it.md
**Register:** claim
**Central commitment (one sentence):** Attempted recovery of each decision-relevant content closure establishes only source-relative recoverability—not provenance, live authority, correctness, or global uniqueness—and a system/document pair is bidirectionally irrecoverable only when each side contains decision-relevant content that neither the other side nor any accessible source can reproduce.

## Premises and counterexamples
1. **A failed reconstruction attempt establishes that the declared sources do not determine the target content, rather than merely that this reconstructor, method, budget, or decoding context failed to extract content the sources do determine.** — DEFEATED — An exact formal specification can contain every value needed to reproduce a parser, yet a recovery agent unfamiliar with the specification language can fail to reconstruct it; the attempted recovery fails although the information is present and a competent generator succeeds. The note gives no completeness condition that separates non-determination from assay failure before treating failure as an informational gap. — GLOBAL — instance
2. **Recoverability is relative to a declared source set, a decision-relevant content unit or dependency-preserving closure, and a consumer goal.** — HOLDS — Adding a generator, removing a shared definition, changing the target from behavioral equivalence to preservation of historical warrant, or changing the content boundary can each reverse a recovery result; active hunting found no source-independent recovery fact once those variables are allowed to vary.
3. **When warrant, constraints, rejected branches, coverage, or epistemic status supported the original decision and remain relevant to the declared consumer goal, faithful recovery must reproduce that actual information rather than invent a different rationale that licenses the same visible result.** — HOLDS — A behaviorally equivalent post-hoc rationale cannot identify which of several observationally compatible histories occurred; active hunting found no case in which substituting a different history preserves the qualified target of recovering the actual decision-support content.
4. **Present artifact contents and their recovery relation can be identical under different production histories, so recovery alone cannot establish provenance.** — HOLDS — The same matching code and document can result from document-first implementation, code-first documentation, or independent derivation from a common requirement; embedded build records or traces can distinguish those histories only by adding the independent lineage evidence the premise says is required.
5. **Present artifact contents and their recovery relation can remain fixed while the artifact that governs the next change changes, so recovery alone cannot establish live authority.** — HOLDS — A generated specification can later be adopted as a compatibility contract, and a once-generative design can become archival, without changing either current artifact; active hunting found no way for the extensional recovery result by itself to distinguish those governance states.
6. **Every recovery target has a unique smallest decision-relevant closure whose selection does not itself make the recovery classification arbitrary.** — DEFEATED — Two redundant specification clauses can each independently determine the same behavior: either singleton is a minimal sufficient closure, their intersection is insufficient, and neither is *the* smallest closure. The assay can retain its central distinction by asking for a declared minimal sufficient closure or by reporting all relevant alternatives, but the singular boundary asserted by the note is not guaranteed. — LOCAL — instance
7. **Content is currently authoritative only if it has a causal path into the live change loop.** — DOUBTFUL — A legally binding accessibility rule can obligate a maintenance team even when the team is unaware of it and no routing, test, tool, or consultation currently carries it into their changes; under the note's own “must consult or obey” wording, normative authority may exist without an operative causal path. Narrowing the premise to *operationally load-bearing authority* would preserve the recovery/provenance distinction. — LOCAL — instance
8. **Failure to recover content from the paired system does not establish global uniqueness, and deleting the documentary copy is irrecoverable only when no surviving accessible source can faithfully reproduce that content.** — HOLDS — An issue tracker or decision record can preserve a rationale absent from code, directly defeating pair-only uniqueness; active hunting found no counterexample to the all-accessible-source condition because any reproducible surviving copy falsifies its antecedent.
9. **If documentation uniquely preserves actual decision-support content that the system does not determine, while the system uniquely fixes resolutions the documentation does not determine, then the pair is irrecoverable in both directions and one artifact-wide source-of-truth assignment misclassifies at least one region.** — HOLDS — Complete formal specifications, introspective systems, and code-first prototypes avoid one or both antecedents rather than refuting the conditional; active hunting found no case satisfying both uniqueness conditions in which either whole artifact could faithfully regenerate the other.
10. **Recoverability neither establishes correctness nor by itself settles whether maintaining or deleting a recoverable copy is worthwhile.** — HOLDS — A faithfully reproduced rationale can be false, while an accurate cache can be derivable but expensive to recompute; active hunting found no necessary implication from information availability to truth or to a favorable store-versus-recompute balance.

## For the human
Look first at premise 1: without a completeness or competence condition on the recovery attempt, failure can identify a weak reconstruction procedure rather than an informational gap in the tested sources.
