# Premise decomposition: An insufficient summary precedes the source rather than replacing it

**Note:** `kb/notes/an-insufficient-summary-precedes-the-source-rather-than-replacing.md`
**Register:** claim
**Central commitment (one sentence):** For a fixed consumed summary, authoritative source path, question, and required reliability, with no other authoritative evidence route intervening, a summary that cannot license the action cannot fully replace the source path in a reliability-compliant answer, and its read-cost value is only the fallback work it removes minus its own consumption cost.

## Premises and counterexamples

1. **Universal: Sufficiency is determined per use by the consumed answer together with the provenance, corroboration, and verification available to that consumer, for the fixed question and required reliability.** — HOLDS — Identical summary text presented to a consumer who can authenticate its provenance and one who cannot initially looked like a counterexample, but the note explicitly makes those two different consumed-summary inputs; an orientation question and an exact-schema question likewise differ in question or required reliability rather than defeating the premise.
2. **Universal: The source path is reachable and can answer the fixed question at the required reliability; if a cheaper equivalent authoritative route can do so, that route is the source-path baseline rather than an escape from it.** — HOLDS — A checked interface can avoid reading the nominal source artifact, but the note defines that interface as the proper source path; a case with no reachable authoritative route is expressly outside this added-read ledger.
3. **Universal: A reliability-compliant answer is a substantive answer that closes the fixed question at the required reliability, rather than any policy-compliant response such as abstention.** — DOUBTFUL — Consider an exact-schema task whose response contract accepts either a warranted field name or an explicit abstention. An approximate summary cannot license the edit, the authoritative source remains reachable, and no other evidence route intervenes, yet the consumer can return the allowed abstention without doing source-path work. The note can exclude this case by fixing answer completeness or task closure alongside reliability, but “same question and reliability” does not explicitly do so. — LOCAL — instance
4. **Universal: For a substantive answer, an unsupported guess, trust in the summary, or accidental correctness does not satisfy the fixed reliability requirement; the route must obtain the warrant that the insufficient summary lacks.** — HOLDS — A reader can act on an inadequate summary and happen to be correct, but that route has not bought the stipulated reliability; treating realized correctness as compliance would change the comparison from warranted reliability to hindsight accuracy.
5. **Universal: If the summary cannot supply the missing warrant and no other authoritative evidence route intervenes, a reliability-compliant substantive answer must retain source-path work.** — HOLDS — Reliable prior knowledge, an independent corroborating artifact, or a fresh experiment could avoid the named artifact, but each is another authoritative evidence route; a deduction from information already available with the summary would instead make that consumed summary sufficient for the question.
6. **Universal: Full substitution requires both sufficiency and an actual stop at the summary, while an insufficient summary may receive partial credit only for discovery, selection, interpretation, or verification work it removes from the fallback.** — HOLDS — A pointer that cannot close the question but directs the reader to the exact source unit is the strongest candidate counterexample; it confirms rather than defeats the premise because it removes selection work without eliminating the fallback.
7. **Universal: In the chosen read-cost currency, total marginal route cost decomposes into disjoint, additive summary-consumption cost and source-path work, so direct-path cost minus summary-routed-path cost equals fallback work removed minus summary consumption cost.** — DOUBTFUL — If “reader time” is elapsed time and independent readers consume the summary for five seconds and the unchanged source path for ten seconds in parallel, the routed result still takes ten seconds rather than fifteen: unchanged fallback plus a positive standalone summary duration does not yield the ledger's negative five-second value. The equation holds if the currency is additive resource consumption, or if “summary consumption cost” means incremental path cost after overlap, but the note fixes a currency without stating either condition. — LOCAL — instance
8. **Universal: A summary that removes no fallback work is a pure addition only to the extent that its marginal consumption cost is positive; routing that avoids consuming it incurs no use-phase summary cost.** — HOLDS — A prefetched summary or a summary covered by a fixed charge can have zero marginal cost, but then it does not meet the positive-marginal-cost condition; creation and maintenance expenditure belongs to the note's separate total-layer ledger.

## For the human

Look first at premise 3: state whether a reliability-compliant “answer” must substantively close the question, because an allowed abstention otherwise avoids source-path work without demonstrating full substitution.
