# Premise decomposition: Productive deferral requires a preserved option, discriminating evidence, and a convergence rule

**Note:** kb/notes/productive-deferral-requires-option-evidence-and-convergence.md
**Register:** claim
**Central commitment (one sentence):** A consequential choice is productively deferred only if at least one option that present commitment would destroy or make costly remains exercisable, some possible later observation or bounded-test output can change the conditional action, and a rule returns the choice to decision early enough with a mapped response, although these conditions do not establish that waiting is worth its cost.

## Premises and counterexamples
1. **A consequential choice can be productively deferred only if some possible later observation or bounded-test output could change its selection, timing, modification, or abandonment; merely rescheduling decision effort cannot itself make the deferral productive.** — DEFEATED — An operations committee must choose one of two already-qualified, price-locked suppliers by Friday. During a production outage on Monday, it deliberately calendars the supplier vote for Friday so the nonurgent but consequential deliberation does not displace incident response. The bids, facts, and tie-break rule will not change, and no test or observation is due. This is a controlled and productive postponement through scarce-attention allocation despite having no discriminating-evidence route; the note states no narrower, action-value-only meaning of “productive” that excludes it. — GLOBAL — instance
2. **A consequential choice is genuinely deferred only when choosing now would destroy an alternative or make it costly to recover and that alternative remains exercisable at the later decision point.** — DOUBTFUL — A release controller can postpone selecting between two high-stakes traffic-routing policies until a latency test at launch time even when either policy can be selected, switched, or cleared atomically and without dependencies or recovery cost until launch. The later evidence can make the postponement useful, but a provisional selection now would not destroy or make either alternative costly under the note's definition. Calling this only delayed finalization rather than a deferred choice assumes the very boundary the premise needs to establish. — GLOBAL — instance
3. **A productive controlled deferral always needs a specified return condition coupled in advance to a mapped response; continuous situational judgment without that pair is merely ad hoc choice.** — DOUBTFUL — An experienced incident commander can deliberately keep an evacuation-route choice open while continuously integrating wind, fire, road, and population observations, and then exercise a route through authorized holistic judgment without a date, threshold, or state-to-response mapping fixed in advance. That is plausibly an ordinary productive form of adaptive deferral rather than unmanaged indecision, although the note's broad allowance for transfer to an authorized procedure could be read to include it. — GLOBAL — instance
4. **If every possible observation leaves the same action preferred, the observation cannot make the named decision better informed.** — DEFEATED — Suppose architecture A dominates B for every server-load value from 40 to 60, while a measurement narrows the load estimate from that interval to 52. A remains preferred, but its expected consequences and the confidence supporting the choice are more precisely informed. The premise can be repaired by saying that the observation has no action-changing value, not that it supplies no better information. — LOCAL — instance
5. **Bounding each newly authorized tranche of work is sufficient for that response to count as convergence even when the rule has no cumulative budget, latest decision point, or terminal action.** — DEFEATED — A weekly rule can say, “if any material uncertainty remains, authorize one more two-day probe.” With noisy evidence, some uncertainty can remain at every review, so every tranche is bounded and every return has a mapped response while the original choice is deferred forever. A terminal bound is needed to keep repeated bounded work from recreating unmanaged indecision. — LOCAL — instance
6. **The cited real-options, rolling-wave, dynamic-pathway, and set-based methods share the complete option–evidence–convergence mechanism rather than contributing different components that the note combines.** — DEFEATED — The cited PMI rolling-wave definition says only that near-term work is detailed while future work remains at a higher level; even paired with progressive elaboration, it states neither an alternative that current commitment would destroy nor a return condition mapped to a response. Githens supplies a replanning date and response separately. The source family therefore contains an instance of component support rather than the asserted full shared mechanism. — LOCAL — instance
7. **A return condition that fires only after the preparation lead time or expiry cannot preserve the option for exercise at the later decision point.** — HOLDS — The strongest apparent exception is intentional expiry, but a rule that deliberately lets an option lapse maps to abandonment or a default action; it does not make the expired option exercisable at the later point. No counterexample preserved actual exercise after feasibility was lost.
8. **One live future exercise choice can supply the option condition; productive deferral need not maintain several parallel alternatives.** — HOLDS — A single exercise opportunity still contrasts exercise with non-exercise, abandonment, or timing, so it presents a real later choice. Cases in which comparison among several candidates is useful show that multiplicity can add value, not that it is necessary for every option-bearing deferral.
9. **Even when an option remains live, evidence can change the conditional action, and a convergence rule returns the choice in time, waiting costs can outweigh the benefit, so the conjunction alone cannot establish net worth.** — HOLDS — A time-critical intervention can preserve a diagnostic option, await a genuinely treatment-changing result, and set an explicit review time while the mortality risk of delay still makes immediate treatment preferable. A costless-waiting case in which the conjunction is enough does not defeat the premise that the conjunction is not sufficient in general.

## For the human
Look first at premise 1: controlled batching can make postponement productive by reallocating scarce deliberative attention even when no evidence could change the eventual action, so the unqualified evidence requirement is globally overbroad.
