# Premise decomposition: The reachability conjecture: train the house, not the LLM

**Note:** kb/articles/the-reachability-conjecture-train-the-house-not-the-llm.md
**Register:** claim
**Central commitment (one sentence):** At least one automated software house capable of open-ended coherent software change is practically reachable with fixed LLMs available by 2026-09-02 by training its surrounding software and persistent notes until no human is needed in an internal production or theory-holding role.

## Premises and counterexamples
1. **There exists at least one combination of admitted 2026-09-02 LLM, product scope, operating horizon, and resource envelope where the fixed model can use retained project-specific state to make coherent novel software changes.** — DOUBTFUL — The article gives the fixed model a role, but it supplies no model-bound evidence that any admitted model can sustain long-horizon, counterfactual-sensitive theory use rather than losing hidden invariants, fabricating rationales, or optimizing for local test passage as novelty accumulates. — GLOBAL — prevalence
2. **Persistent natural-language notes and executable software can retain the decisive project-specific theory in a form a fixed LLM can later apply and revise.** — DOUBTFUL — A declared scope may depend on judgments that are exposed only indirectly, such as business risk tolerance, social acceptability, legal prudence, or workflow norms; if those judgments never become legible in notes, traces, tests, or tool outputs, the retained state underdetermines coherent change. — GLOBAL — priced-exception
3. **Production consequences can be attributed well enough to admit successor notes and software that improve later production.** — DOUBTFUL — Delayed and confounded feedback can make the causal lesson of a change ambiguous: the same failure may trace to code, a dependency, a context route, a stale note, a user-workflow shift, or an earlier validator, so the house can retain the wrong rationale and degrade later work while still completing the update loop syntactically. — GLOBAL — instance
4. **The training path can outgrow repeated human authorship of the decisive project-specific theory rather than merely run inside human-authored scaffolding that still carries that theory.** — DOUBTFUL — A seed made of validators, schemas, prompts, context routers, interfaces, and acceptance harnesses can continue to determine which changes count as coherent; in that case the successor notes and software look learned, but the decisive theory remains in the hand-built scaffold. — GLOBAL — instance
5. **A declared product scope and horizon can be both genuinely open-ended and bounded enough to test practical reachability.** — DOUBTFUL — A narrow scope can collapse into a disguised fixed task set that the seed machinery already anticipates, while a broad scope can make the no-human-theory-holder condition practically uncloseable; either case leaves the witness short of the stated open-ended but bounded target. — GLOBAL — instance
6. **The witness can keep external user input distinct from a human occupying an internal production or theory-holding role.** — DOUBTFUL — A user who repeatedly explains why proposed changes fit, diagnoses failed rationales, or supplies the missing domain theory can become the de facto theory holder even when the protocol labels those interventions as requirements, feedback, domain knowledge, or acceptance judgments. — GLOBAL — instance
7. **A computational house can pass Naur's functional test without reducing program theory to a finite set of formulated criteria.** — DOUBTFUL — An LLM may fluently cite a rationale and make locally plausible edits while failing the counterfactual sensitivity that distinguished Naur's original team, for example accepting a design that violates an unstated architectural purpose because the written note names the reason but not its boundary conditions. — LOCAL — instance
8. **Current LLMs can produce computationally caused retained changes to both software and notes that affect later production.** — HOLDS — The article's examples are modest but adequate for the premise: adding a validator after a recurring bug class, then having that validator block later bugs, is an experience-caused retained change that shapes later production; the counterexample hunt found measurement disputes but not a defeat of the premise as stated.
9. **The four witness obligations are sufficient to demonstrate open-ended coherent software change by a trained house.** — DOUBTFUL — A system might satisfy the listed demonstrations on selected episodes while failing untested but practically central properties such as regression recovery, adversarial user pressure, distribution shift inside the declared horizon, or resource collapse; that would meet the visible obligations without establishing the operational capacity the commitment needs. — GLOBAL — instance
10. **The Bitter Lesson does not categorically disfavor learned legible software and notes, because it selects behavior-shaping production methods rather than retained representational form.** — HOLDS — Objections about efficiency or scaling remain available, but retained legible artifacts produced through search over experience are not defeated merely by being software or natural-language notes.
11. **Autonomous continuation across novel changes does not require the production machinery to be fully self-modifying in advance.** — HOLDS — The article prices the exception: if the declared scope requires machinery change, the automation obligation includes that change; if the scope does not require it, fixed general machinery is not itself a counterexample.
12. **Failure of one architecture cannot refute the existential reachability claim unless the search space has first been bounded.** — HOLDS — The commitment is existential over model, arrangement, scope, horizon, and resource envelope, so a failed implementation path leaves another possible witness unless the test protocol first commits to an exhaustive search boundary.

## For the human
Look first at premise 4: the article needs the sharpest boundary between learned successor theory and human-authored scaffolding that still performs the decisive theory work.
