# Premise decomposition: Addressability grain, not compression ratio, sets a matched selective-read floor

**Note:** kb/notes/addressability-grain-not-compression-ratio-decides-whether-a.md
**Register:** claim
**Central commitment (one sentence):** For recoverable cache content and a known question that selects one answer-bearing unit through each access path, the relative read floor is determined by the two selected units, so a summary lowers that floor only when its addressable unit is finer than the source unit and whole-artifact compression ratio alone cannot decide the comparison.

## Premises and counterexamples

1. **For an access path, the smallest unit it can return without loading the rest is the minimum amount of candidate material that a reader can retrieve through that path.** — HOLDS — Range reads, symbol extraction, and precise search snippets initially appear able to retrieve less than a declared unit, but each would expose a smaller addressable unit under the note's access-path-relative definition; no case was found in which the path retrieves less while its smallest retrievable unit remains larger.
2. **Under the matched one-unit conditions, the question selects exactly one explicit answer-bearing unit on each side through a known discriminating key, without fan-out, discovery, or multi-location reconstruction adding further units.** — HOLDS — Repeated terms, unfamiliar vocabulary, distributed invariants, and multi-hit search all force extra reads, but each violates an explicit matching condition rather than furnishing a counterexample inside it; no in-scope case was found that requires more than the selected unit.
3. **Addressability grain across the two artifacts is commensurate with the amount of material delivered to the reader, so calling one unit finer is enough to say that its read floor is lower.** — DOUBTFUL — Consider a 200-token summary paragraph uniquely addressed by a heading and a 40-token source file retrievable only as a whole: the summary unit is structurally and topically finer, yet it places more material in context. The note does not define whether cross-artifact “finer” means semantic scope, structural nesting, bytes, tokens, or another cost measure, so grain alone does not order the floors unless the intended common measure is made explicit. — GLOBAL — instance
4. **Once selected-unit cost is measured on a common read-volume scale, retrieving a smaller summary unit lowers the one-unit floor, while an equal or larger summary unit cannot lower that floor.** — HOLDS — Fixed lookup latency, semantic effort, maintenance cost, and answer reliability can reverse total net value, but the note expressly separates them from the selected-material floor; no counterexample was found to the scoped comparison itself.
5. **Whole-artifact compression ratio alone is not a sufficient statistic for the relative sizes of the two units selected by a question.** — HOLDS — Two source-summary pairs can both have totals of 1,000 and 100 tokens while the first selects 200 versus 10 tokens and the second selects 5 versus 50; the identical whole-artifact ratio accompanies opposite selected-unit comparisons, and the active hunt found no way for the ratio alone to recover the missing unit distribution.
6. **In every matched selective read covered by the claim, the reader consumes neither artifact in full.** — DEFEATED — A 40-token configuration file and its one-paragraph summary can each be a single addressable unit for a known question, so selecting one unit consumes both artifacts in full; the note's Scope section also admits that a whole artifact is the governing addressable unit when the path loads it whole. Replacing “does not consume” with “need not consume” preserves the ratio argument because totals still fail to encode selected-unit sizes in the general case. — LOCAL — instance
7. **Whether the selected material is sufficient, reliable, current, or cheaper to maintain can be tested separately from how much material the access path must retrieve.** — HOLDS — An insufficient summary can force a subsequent source read and thus lose on completed-task cost, but it still has a determinate first-read retrieval floor; the note limits its commitment to that component and does not infer positive net value from grain alone, so no counterexample was found to the separation as stated.

## For the human

Look first at premise 3: the central comparison needs an explicit common measure of selected-unit size, because structural or topical fineness can diverge from the bytes or tokens that actually set a read-volume floor.
