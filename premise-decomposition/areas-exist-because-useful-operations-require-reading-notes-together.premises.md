# Premise decomposition: Areas exist because useful operations require reading notes together

**Note:** `kb/notes/areas-exist-because-useful-operations-require-reading-notes-together.md`
**Register:** claim
**Central commitment (one sentence):** When a knowledge-base operation must reason across multiple notes within a bounded working context, it needs an operation-relative bounded read-together cohort ("area"), while the cohort's concrete implementation remains contingent.

## Premises and counterexamples
1. **Some useful knowledge-base operations derive their output from relationships among multiple notes, so one-at-a-time retrieval by itself cannot produce those outputs.** — HOLDS — Active counterexample hunt did not find a concrete way to detect contradiction, redundancy, tension, or missing links from isolated retrieval alone; any apparent counterexample reintroduces joint comparison in a later step.
2. **Whenever such an operation must reason across notes in one bounded working context, that pass needs some bounded jointly processed candidate set rather than an unscoped whole-library read.** — HOLDS — Active counterexample hunt did not find a case within the note's stated scope where cross-note reasoning happens in one bounded context without selecting at least a temporary batch, pair set, or equivalent frontier.
3. **Capacity and expected comparative or orientation yield are jointly usable before the pass to set a good cohort boundary, so fixed cardinality, universal membership rules, or taxonomy alone are not the real determinant of scope.** — DOUBTFUL — A newly written bridge note can connect two previously separate topics while carrying little overlap in tags, titles, or existing links, so the relationship most worth comparing is not predictably visible until some exploratory reading has already happened. That concrete case does not refute the broader boundary argument, but it does show that ex ante expected-yield estimation can be too weak to do all the routing work the premise assigns it. — LOCAL — instance
4. **Operational cohorts and classifications answer different questions often enough that no particular tag scheme, hierarchy, or index layout follows from the need for joint reading.** — HOLDS — Active counterexample hunt found cases where a taxonomy and an operation-specific cohort can coincide, but not a reason they must coincide generally; the coincidence looks contingent on local design rather than entailed by bounded-context reasoning.

## For the human
Look at premise 3 first: the note's boundary argument depends on "expected yield" doing real operational work, but the note does not yet show how that quantity is available reliably enough to guide cohort construction.
