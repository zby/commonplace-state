# Connection Report: LLM Position Bias Benchmark (Swapped-Order Pairwise Judging)

**Source:** [Ingest: LLM Position Bias Benchmark](../../../../sources/position-bias.ingest.md)

The source is an `.ingest.md` whose Connections Found / Extractable Value sections are still `TO BE FILLED`. The underlying data-and-reports snapshot lives at `kb/sources/position-bias/` (immutable). All candidates below are for a future edit of the ingest report, not for the snapshot.

Core finding to connect around: across 27 LLM judges, the median model flips its underlying pairwise winner in 44.8% of decisive cases when display order is swapped on identical story pairs; model-dependent first-position lift rates are large and structured, not a uniform tiebreaker. This is empirical evidence about judge reliability under prompt-level perturbation, not a paper on how to mitigate it — the mitigation vocabulary (order-swap, Borda) already exists in the KB.
