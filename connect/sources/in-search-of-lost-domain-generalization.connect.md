## Connections Found

Candidates for a **future edit of the ingest report**. The ingest already authors the reach-assessment cluster, the codify/relax head, the definition, and the three closest source siblings; the entries below are the ones it does not carry.

- [Fixed artifacts split into exact specs and proxy theories](../../../../notes/exact-implementation-does-not-validate-a-requirement.md) — **evidence**: each DG algorithm is a proxy theory about what makes generalization work, correct against its own objective and unproven against the system-level capability. The paper supplies a tell the note does not list — parity with a well-tuned general baseline under a declared selection protocol, detectable without waiting for composition failure. The ingest reaches this note only indirectly, through `codification-and-relaxing`.
- [First-principles reasoning selects for explanatory-reach over adaptive fit](../../../../notes/first-principles-reasoning-selects-for-explanatory-reach-over.md) — **evidence**: the note holds that explanatory-reach claims stay accountable to observed fit and to rival-practice tests. DomainBed is that accountability enforced on a whole subfield — reach claims (invariance across environments) that did not survive a protocol measuring them against the rival practice. Precedent for the label: [EsoLang-Bench](../../../../sources/esolang-bench-evaluating-genuine-reasoning-via-esoteric.ingest.md) already carries an evidence edge to this note for the structurally identical reason.
- [The No Free Lunch Theorem](../../../../sources/no-free-lunch-theorem-no-universal-learning-algorithm.ingest.md) — **compares-with**: NFL says a strategy wins only where its assumptions match the problem distribution; this paper measures a case where the specialized assumptions did not pay on the seven distributions tested, and — via claim (A) — shows part of the apparent payoff was protocol artefact rather than assumption match.
- [Huxley-Gödel Machine](../../../../sources/huxley-godel-machine-human-level-coding-agent-development.ingest.md) — **compares-with**: the same defect in a different search. HGM's thesis is that the *selection signal* used inside an experimental protocol (immediate benchmark score for parent selection) silently determines which lineage appears to win; DomainBed's claim (A) is that the selection signal (which validation set picks checkpoints) silently determines which algorithm appears to win. Two independent demonstrations that the selection rule belongs in the method description, not the appendix.
- [EsoLang-Bench](../../../../sources/esolang-bench-evaluating-genuine-reasoning-via-esoteric.ingest.md) — **compares-with**: both are benchmark-validity critiques with opposite instruments. EsoLang-Bench moves the task off the pretraining distribution to show reported coding scores measure fit; DomainBed holds the tasks fixed and declares the selection protocol to show reported DG advantages measure protocol. A reader building a case that a headline number is an artefact wants both.
- [Towards a Science of Scaling Agent Systems](../../../../sources/towards-a-science-of-scaling-agent-systems.ingest.md) — **compares-with**: the closest methodological sibling in the KB — 180 controlled configurations across models and benchmarks, whose result is that the apparent effect ("multi-agent wins") is contingent on properties the original comparisons left undeclared. Same testbed-over-anecdote move DomainBed makes for domain generalization.
- [Natural-Language Agent Harnesses](../../../../sources/natural-language-agent-harnesses.ingest.md) — **compares-with**: a second controlled null result on explicit structure — module ablation finds added structure improves nothing unless it tightens alignment with the evaluator's acceptance criteria. Read next to claim (B), the pair says the payoff of an explicit inductive bias is an empirical question that fair ablation frequently answers "no".
- [Position bias](../../../../sources/position-bias.ingest.md) — **compares-with**: the cleanest instance of claim (A)'s general form outside supervised learning. An undeclared protocol variable (answer order for a judge; validation signal for DG) flips the reported winner in a large fraction of cases, so a result reported without that variable fixed is not a result about the method. `operational-signals-…` already cites this source, which makes the parallel navigable from the notes side too.

## Synthesis Opportunities

Three, none created here.

1. **A declared selection protocol is part of a result's identity.** DomainBed's claim (A), [position bias](../../../../sources/position-bias.ingest.md) (answer order flips the reported winner), [Huxley-Gödel Machine](../../../../sources/huxley-godel-machine-human-level-coding-agent-development.ingest.md) (parent-selection signal determines which lineage wins), and the review system's own model partition ([README-REVIEW-SYSTEM](../../../../reference/README-REVIEW-SYSTEM.md)) are four independent instances of one claim: an evaluation result reported without its selection variable fixed is not a result about the method under test. The KB has all four pieces and no note stating the general form, which would be directly operational for gate and sweep design. This is new to this run.

2. **A protocol-parity relaxing signal.** [Operational signals that a component is a relaxing candidate](../../../../notes/operational-signals-that-a-component-is-a-relaxing-candidate.md) lists five early signals plus composition failure as the late one. This paper demonstrates a sixth fitting neither slot: *a specialized component's advantage disappears once the general baseline is tuned under the same declared selection protocol*. Cheaper than composition failure and diagnosing a different fault — not that the component's theory is brittle, but that the comparison establishing its value was never fair. Combined with [an outcome check licenses replay](../../../../notes/checked-outcome-licenses-episode-retention-not-abstraction.md), the general form is: an unverified selection process makes an outcome check look like a process check. The ingest records this as extractable value #2; it is still unwritten.

3. **"Reach predicts bitter-lessoning" now has a test case.** [wikipedia-bitter-lesson.ingest.md](../../../../sources/wikipedia-bitter-lesson.ingest.md) flags as unwritten the conjecture that higher-reach methods resist being bitter-lessoned. The DG algorithms made explicit reach claims (invariance across environments) and were bitter-lessoned anyway — a data point against the naive form. The tension is already registered inside [reach-assessed-commitments-…](../../../notes/reach-assessed-commitments-may-cut-target-observations-under-shifts.md), which concedes the bitter-lesson reading is "not rebutted here."
