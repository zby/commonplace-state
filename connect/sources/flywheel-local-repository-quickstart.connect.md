## Connections Found

- [Enforcement without structured recovery is incomplete](../../../../notes/enforcement-without-structured-recovery-is-incomplete.md) — **is-evidence-for**: the quickstart documents more than rejection: invalid edits preserve staging, failures identify the offending operation, and invalid saved batches have an explicit digest-guarded discard route. This is a documented recovery design, not evidence that discard repairs the intended graph or that recovery is automated.
- [Error messages that teach are a constraining technique](../../../../notes/error-messages-that-teach-are-a-constraining-technique.md) — **is-evidence-for**: superseded commands fail without mutation and print their exact `repo:` or `hosted:` replacement, placing the next action in the failure output instead of requiring a fresh command search. No outcome benefit is measured here.
- [Freshness architecture](../../../../reference/freshness-architecture.md) — **see-also**: both designs distinguish the state inspected from later current state and reject stale expectations. Flywheel binds pending views and cursors to a staging digest and committed base; Commonplace binds review evidence to captured inputs and protects baseline transitions with revisions. These are analogous concurrency concerns over different objects.
- [beads_rust](../../../../agentic-systems/reviews/beads-rust.md) — **compares-with**: both place local mutation checks near the write boundary and separate local work from external publication. The review gives code-grounded compare-and-set claims and explicit Git transport boundaries, while Flywheel's supplied documentation describes pending-batch validation and its own separate push operation. Do not imply equivalent distributed coordination or interface parity.
- [Semiont](../../../../agent-memory-systems/reviews/semiont.md) — **compares-with**: compare stale-update handling in collaborative graph work. Semiont's reviewed body operations replay in event order without an `If-Match` check; Flywheel documents rejection when the local head or pending batch changes during an edit and invalidates staged pagination cursors on such changes.
- [Agora: Git as Shared Memory for Collective AutoResearch](../../../../sources/agora-git-as-shared-memory-for-collective-autoresearch.ingest.md) — **compares-with**: Agora makes immutable contributions and parent commits its research record; Flywheel separates editable pending graph values, a local durable commit, and explicit hosted publication.
