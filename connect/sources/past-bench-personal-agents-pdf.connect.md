## Connections Found

- [Evaluate Memory By Effects, Not By Existence](../../../../notes/agent-memory-requirements/evaluate-memory-by-effects.md) — **is-evidence-for**: matched persistence-on/off evaluations measure later task effects separately from artifact and telemetry evidence; equal headline gains can conceal different observed persistence pathways. This is the strongest target for a later note update.
- [Activate Behavior-Changing Memory Before The Mistake](../../../../notes/agent-memory-requirements/activate-behavior-changing-memory.md) — **is-evidence-for**: E1 checks retained constraints before planning and E4 requires retrieval before a recall-dependent response; their diagnosed failures distinguish stored state from timely consultation. Component results are capability-specific, not universal guarantees.
- [Retire, Redact, Supersede, And Relax Memory](../../../../notes/agent-memory-requirements/retire-redact-supersede-relax.md) — **is-evidence-for**: Update families test corrected values and expired exceptions in later fresh sessions; E2 rendering and E5 closeout give concrete mechanisms for suppressing obsolete state. The evidence concerns supersession and expiry, not every lifecycle operation in the note.
- [Knowledge-access architecture must be evaluated end to end](../../../../notes/knowledge-access-architecture-must-be-evaluated-end-to-end.md) — **is-evidence-for**: the benchmark separates task gains, persistence events, and cross-session update failures, supplying a bounded empirical case for keeping access diagnostics distinct from downstream success. It does not measure the note's full upkeep burden.
- [Hermes Agent](../../../../agent-memory-systems/reviews/hermes-agent.md) — **compares-with**: compare the reviewed native memory/skill/history surfaces with interventions that change when those surfaces are consulted, rendered, written, and flushed. The local review is pinned to July commit `d59b79f`; PAST-Bench uses Hermes v2026.4.16 and benchmark adapters, so findings must not silently update the review's implementation claims.
- [Large Language Model Agents are not Always Faithful Self-Evolvers](../../../../sources/llm-agents-are-not-always-faithful-self-evolvers.ingest.md) — **compares-with**: persistence removal and pathway telemetry address different attribution questions from corrupting or replacing specific memory content. PAST-Bench's Mech includes outcome-derived components and keyword/count proxies; it is not proof that the intended content caused an action.
- [Memento-Skills](../../../../sources/memento-skills-let-agents-design-agents.ingest.md) — **compares-with**: Memento separately measures routing and trajectory success while ablating skill optimization; PAST-Bench toggles retained-state access in fresh-session task families. Their controls identify different effects and can inform complementary evaluation layers.
- [Continual Harness](../../../../sources/continual-harness-online-adaptation-foundation-agents.ingest.md) — **compares-with**: persistent reset-free progress and create-but-never-consult artifacts contrast with PAST-Bench's context-clearing matched controls. The shared question is whether retained artifacts improve later behavior, with different confounds and task distributions.
- [Ablation baselines for the declared objective](../../../../reference/proposals/ablation-baselines-for-the-declared-objective.md) — **see-also**: PAST-Bench supplies a concrete fresh-session, fixed-model persistence-toggle protocol to consider when designing repository-task ablations; it does not measure human-judgment cost or validate Commonplace's objective.
