## Connections Found

All six are new outbound candidates. Labels are authorized by the sources collection for their respective destination collections.

- [An experiment identifies only the contrast it actually runs](../../../../theory/an-experiment-identifies-only-the-contrast-it-actually-runs.md) — **compares-with**: Basal's release comparison changes weights, prompts, calibration and serving configuration together. The note gives the evaluation reader a concrete test for keeping attribution at release-bundle grain rather than calling the result an isolated fine-tuning gain.
- [Calibrating semantic gates against labelled fixtures](../../../../reference/proposals/calibrating-semantic-gates-against-labelled-fixtures.md) — **see-also**: its separation of known-case regression from sampled field calibration directly informs a future routing test's labels, hidden evaluation cases and scope of reported error rates. Adapt the evaluation design; do not treat the proposal as shipped policy or equate gate detection rates with selective-routing error.
- [Content routing](../../../../reference/content-routing.md) — **see-also**: its content-kind, consumer and destination distinctions supply an existing specification surface from which human-adjudicated routing examples could be constructed. The rows are not automatically mutually exclusive labels; multi-contribution and out-of-scope cases still need an explicit response policy.
- [There Is No Neutral Harness](../../../../sources/no-neutral-harness-config-fragile-items.ingest.md) — **compares-with**: both make answer presentation and option order part of the measured configuration. The harness study supplies a reason to retain item-level stability results alongside aggregate scores when testing Basal's order-specific calibration. Its different models and interfaces do not prove Basal has the same fragility.
- [AI Components for a Deterministic System](../../../../sources/eric-evans-ai-components-deterministic-system.ingest.md) — **compares-with**: Evans separates taxonomy creation from application, while Basal scores caller-defined options. Following this comparison helps a dataset author test category adequacy separately from assignment accuracy; neither source's consistency or calibration validates Commonplace's chosen route set.
- [Assessing LLM Reasoning in Evidence-Based Claim Verification](../../../../sources/assessing-llm-reasoning-evidence-based-claim-verification.ingest.md) — **compares-with**: RECV excludes unverified cases and forces binary verdicts, whereas Basal reports a threshold-based deferral policy. This contrast makes it useful to include ambiguous and insufficient-information KB cases and score accepted-case error with coverage. Threshold deferral is not itself a semantic `INSUFFICIENT EVIDENCE` class, and no matched performance comparison was run.
