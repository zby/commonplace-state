## Connections Found

- [Epiplexity by example: what entropy and complexity miss](../../../../notes/epiplexity-by-example-what-entropy-and-complexity-miss.md) -- **compares-with**: the coffee automaton shows that measured apparent complexity depends on a chosen coarse-graining and compressor; epiplexity makes the omitted observer, tool, and compute dependence explicit.
- [Information value is observer-relative](../../../../notes/information-value-is-observer-relative.md) -- **is-evidence-for**: the chapter's compression examples repeatedly change value with the decoder, coarse variables, tolerated loss, task, and computational resources rather than locating useful structure in bytes alone.
- [A proximate target is checked for achievement, not for warrant](../../../../notes/a-proximate-target-is-checked-for-achievement-not-for-warrant.md) -- **compares-with**: description length is measurable, but its warrant as a proxy for generalization depends on the compressor, function-space tolerance, optimizer, data distribution, and task; low description length alone does not certify the broader objective.
- [Parametric reproduction alone cannot replace an authoritative record](../../../../notes/parametric-reproduction-cannot-replace-an-authoritative-record.md) -- **compares-with**: the “blurry JPEG as interface” account explains utility but not identity, integrity, currentness, attribution, or contestability, so it cannot license replacing an authoritative source with model weights.
- [Reflection buys addressability](../../../../notes/reflection-buys-addressability.md) -- **compares-with**: grokking and weight compression are cumulative non-reflective improvement, but their simplified distributed representation remains only indirectly addressable; compression is not reflective retention.
