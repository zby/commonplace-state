# Connection Report: The Use of Proximal Information Scent to Forage for Distal Content on the World Wide Web

**Source:** [Pirolli, proximal information scent / distal content](../../../../sources/.snapshots/pirolli-proximal-information-scent-distal-content.md)

The source is a **snapshot** and therefore immutable and never a durable link target. Every candidate below is a recommendation for the authored surface — the matching `kb/sources/pirolli-proximal-information-scent-distal-content.ingest.md`, **which does not exist yet** (checked 2026-08-24). Nothing here can be authored until it does. The source link above is report-local only.

What the source establishes, in its own terms:

1. **Lens-model framing** — navigation is judgment of unobserved *distal* content from observed *proximal* cues (link summaries, snippets, node labels), with a measurable *ecological validity* between the two. Davison (2000): elaborated anchor text to linked page r = .16, to random page ≈ 0; page-pair similarity falls sharply with link distance.
2. **A mechanism** — a Bayesian rational analysis (log-odds, Eq. 5–6) mapped onto ACT-R spreading activation `Ai = Bi + Σj Wj Sji` (Eq. 7) plus a Random Utility Model choice rule (multinomial logit, Eq. 10). Association strengths are estimated from corpus co-occurrence; PMI equals the inter-chunk strength `Sji`.
3. **Empirical fit** — SNIF-ACT against 189 coded actions from 4 participants (of N = 14 Stanford students, 6 tasks). Higher-scent links are the ones followed, χ²(1) = 15.46, p < .0001; predicted link-rank distribution differs from random, χ²(30) = 18,589, p < .0001.
4. **A stopping rule** — patch-leaving: scent declines across a run of pages, then the user switches site (Fig. 9, 13); high start-page scent predicts longer runs, χ²(1) = 8.69, p < .005. Low-scent tasks push users into the keyword problem space (~3.25 vs ~1.25 result sets).
5. **Three problem spaces** — link, keyword, and URL, distinguished in the protocol coding, with mode-switching driven by scent quality.
