## Synthesis Opportunities

The ingest, the scheduler-theoretic ingest, agno-agentos, Claude Code dynamic workflows and the design-space note together imply a claim about durability strategies: what a durable orchestration runtime makes coherent depends on the strategy. Effect-result replay makes only effect results durable. A resource-free interpreter snapshot makes the whole interpreter durable. Reified shared state needs merge rules or disjoint writers. This is the ingest's Extractable Value item 3. Per the fold-claims preference, it should go into the practical-scheduler note's Scope section rather than a new note.
