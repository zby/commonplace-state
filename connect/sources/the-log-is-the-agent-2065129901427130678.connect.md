Source claim (for articulation tests): an agent *is* its durable event log — every input, output, tool call, and tool result, append-only, plus a versioned reference to the session definition. Runtime, model, and tools are interpreters/appenders over that log; any executor can reconstruct state from the log and resume. Compaction is a lossy projection, not the log. System properties (reliability, scalability, forking, multiplayer, migration) fall out of treating the log as the primitive. Owning the log = owning the agent; provider-hosted logs are the deepest lock-in.
