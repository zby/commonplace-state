# Friction check: Only derivation and inheritance warrant a decomposition's scope claim; discriminating use earns it

**Note:** kb/notes/only-derivation-and-inheritance-warrant-a-scope-claim-use-earns-it.md
**Central claim (one sentence):** Derivation from independently supported constraints gives a decomposition a conditional starting warrant, inheritance from discriminating source tests gives it a transferred starting warrant, free choice gives it none, and only refutation-capable use earns broader scope.

## Filter
**Verdict:** SURVIVES
The claim assigns compatible roles to provenance and testing: provenance determines the kind of starting warrant, while refutation-capable evidence determines how much broader scope has been earned.

## Signal — thinnest joints
1. **“When independently supported causal or operational constraints fix the axes, that support supplies the conditional's antecedent.”** — UNSUPPORTED — Fixing which axes generate the cells does not establish that those axes mark consequential distinctions in unseen cases; the note explicitly concedes this, so mechanical exhaustiveness has not yet been connected to the scope claim it is said to warrant.
2. **“Representational form ... is derived from the axes of consequence-assignment and localization.”** — UNSUPPORTED — The instance names axes and their generated cells but supplies no independent support that fixed those axes, leaving it unable to distinguish derivation from an axis choice that the note's own test would classify as free.
3. **“A reflective system ... is inherited. ... Because the source evidence concerns interpreters and metaobject protocols, applying those criteria ... creates a separate bridge claim.”** — UNSUPPORTED — Lineage establishes borrowing, not that the source ontology survived discriminating tests, so the instance does not establish the premise required for a transferred starting warrant.
4. **“It licenses the decomposition in a target domain only while the constraints that made its boundaries consequential at the source also hold at the target.”** — THIN — Matching the named source constraints may be necessary, but the note does not show it is sufficient: target-specific interactions could make the inherited boundaries inconsequential even when those constraints persist.
5. **“A boundary underdetermined by constraints or evidence ... should therefore remain cheap to replace.”** — THIN — Lack of epistemic scope warrant supports revisability, but does not by itself establish a low-cost implementation policy when coordination, interoperability, or migration constraints may independently justify entrenchment.

## For the human
Look first at the derivation step: explain why axes fixed by independently supported constraints warrant consequential scope rather than merely generating an exhaustive cross-product.
