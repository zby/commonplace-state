# Friction check: Promotion selects for unreliable activation, and the regress ends only at an external trigger

**Note:** kb/notes/promotion-selects-for-unreliable-activation-and-the-regress-ends-only.md
**Central claim (one sentence):** Promotion should select a conclusion for activation value when a cost-effective content-and-delivery package closes an unprompted-application gap, which requires the delivery path to be rooted in a live trigger that does not itself depend on the missing activation.

## Filter
**Verdict:** SURVIVES

## Signal — thinnest joints
1. **“Evidence can come from recorded operational misses or controlled open-versus-probed trials. … Without either source, activation-based selection degrades into guessing which conclusions the consumer is unlikely to raise.”** — UNSUPPORTED — Naming two useful evidence channels does not establish that they exhaust the evidence: package telemetry, prior evaluations, natural experiments, or a causal audit of a known firing mechanism could constrain the estimate without fitting either stated source exactly.
2. **“An open-versus-probed performance gap—the difference between unprompted performance and performance after the relevant concern is explicitly raised—can estimate the activation value available to capture.”** — THIN — Raising a concern can add framing, selection guidance, or task information as well as activation, so the observed gap does not isolate activation value or show how much of it a retained delivery package can capture without tighter control of what the probe supplies.
3. **“A note reached only after the consumer independently surfaces the same concern does not close the gap: its delivery depends on the very condition it was meant to supply.”** — THIN — Surfacing a broad concern can be a legitimate cue while the note supplies a more specific conclusion or application procedure; the circularity follows only when retrieval already requires the target conclusion or the next routing instruction, a narrower condition the note states later.
4. **“Symbolic routing can react only after a usable symbol exists, so an occasion that nothing in the workflow names requires either a costlier always-loaded slot or a probabilistic classifier.”** — THIN — The lack of a current symbol supports the limit on current symbolic routing, but it does not by itself make the two proposed remedies exhaustive without ruling out workflow redesign, a new observable event, or a human-provided discriminating cue—or explicitly classifying all such recognizers under the second branch.
5. **“As knowledge storage does not imply contextual activation, retained support can also help when a consumer can produce a conclusion on request but does not reliably raise and apply it unprompted.”** — THIN — The non-implication establishes room for an application gap, but not that retention will improve it; that bridge needs the later package-level delivery and effects test, rather than following from the cited storage/activation distinction alone.

## For the human
Look first at whether the note means recorded misses and open-versus-probed trials as examples or as an exhaustive evidence boundary, then tighten what an open-versus-probed gap can actually identify.
