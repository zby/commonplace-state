# Friction check: Human analogies can motivate functions without determining component boundaries

**Note:** kb/notes/human-analogies-suggest-functions-not-component-boundaries.md
**Central claim (one sentence):** Human analogies may motivate agent functions and failure modes, but component boundaries require separate evidence that the target shares the causal dependencies that make the human coupling useful.

## Filter
**Verdict:** SURVIVES
The claimed properties coexist: an analogy can nominate a functional constraint while leaving allocation open until structural and target-specific comparisons narrow it.

## Signal — thinnest joints
1. **“Because those functions appear unified in one person, however, the analogy can also lead designers to inherit a component decomposition before comparing alternatives.”** — UNSUPPORTED — The note gives no observation or example showing that perceived unity in a person causes designers to copy human component boundaries; it states the motivating failure mode without establishing it.
2. **“When a transferable mechanism depends on shared state, recurrence, or joint adaptation, those dependencies constrain the third answer.”** — UNSUPPORTED — Shared state, recurrence, and joint adaptation can each span an interface, so naming them does not yet show which allocations they exclude or favor.
3. **“A human analogy can support coupling when structural comparison shows that the target shares the relevant causal dependencies.”** — THIN — Shared dependencies support transferring a mechanism, but support for coupling additionally requires showing that separation would break or materially weaken those dependencies in the target.
4. **“These considerations can narrow the choice without determining it.”** — THIN — The note names comparison dimensions but gives no decision rule or worked comparison showing how a dimension eliminates or favors an allocation.
5. **“If the function survives but the boundary moves, the function has support while the inherited allocation remains a design choice.”** — HOLDS — Independent support for the function together with a viable rival allocation establishes that the human boundary is not required by that functional support.

## For the human
Specify how each allegedly shared causal dependency discriminates between coupled and separated allocations in the target.
