# Friction check: Soft degradation often constrains agent work before hard token limits bind

**Note:** `kb/notes/agent-context-is-constrained-by-soft-degradation-not-hard-token-limits.md`
**Central claim (one sentence):** For quality-sensitive agent work whose needed evidence still fits in the provider window, usable context is often limited first by silent degradation from volume, interference, and complexity rather than by the hard token cap.

## Filter
**Verdict:** SURVIVES

## Signal — thinnest joints
1. **"That pattern is consistent with volume, interference, and dependency depth competing for representations needed by the active task."** — UNSUPPORTED — The J-space evidence shows a selectively engaged subspace matters for flexible multi-step tasks, but the note does not show that long-context volume, distractors, and compositional depth all degrade through competition in that same workspace.
2. **"Agent prompts inherit that risk whenever they require recovery from long, weakly scoped input."** — THIN — The lost-in-the-middle result establishes position-sensitive retrieval weakness, but the transfer from that setup to general agent prompting is asserted more than demonstrated.
3. **"This does not prove that retrieval is generally weak, but it does show that interference can survive a retrieval layer."** — THIN — The benchmark supports persistence in one web-agent setup, but the note does not separate interference surviving retrieval in principle from that particular retrieval design being inadequate.
4. **"These are rational responses to a boundary that cannot be measured once for all tasks."** — THIN — The note supports caution about a task-dependent soft bound, but it does not directly establish that selective loading, decomposition, frontloading, and scoped state are the right remedies across the named failure modes.
5. **"Default-loading session history squanders that control."** — THIN — The earlier interference argument makes this plausible, but the note does not show that default history loading is usually net harmful rather than sometimes worth its recall benefit.
