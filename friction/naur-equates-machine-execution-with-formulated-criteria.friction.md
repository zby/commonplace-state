# Friction check: Naur's inexpressibility argument does not by itself make program theory human-only

**Note:** kb/notes/naur-equates-machine-execution-with-formulated-criteria.md
**Central claim (one sentence):** Naur's claim that program theory cannot be captured as formulated criteria does not by itself make program theory human-only, because learned recognizers separate absent human-written rubrics from impossible formal execution while leaving theory possession to further transfer tests.

## Filter

**Verdict:** SURVIVES
The claim has one consistent shape if "formulated criteria" means a human-articulated rubric rather than any executable machine state. Under that limit, the note can accept Naur's inexpressibility claim, deny the inference from no rubric to no machine-effective judgment, and leave broader human-possession premises open. The claim would dissolve only if "rules" already included every finite executable parameter state, but the note explicitly brackets that broader reading.

## Signal — thinnest joints

1. **"A trained face classifier supplies the countermodel."** — THIN — The example establishes machine execution without a programmer-written visual rubric, but it is not itself a program-modification judgment. The note needs the reader to accept that Naur's bridge premise is broad enough for a non-programming recognition case to refute it.
2. **"A learned recognizer blocks that bridge."** — THIN — The block works only after the bridge is narrowed to human-formulated criteria. If Naur's rule premise treats learned parameters as executable rules, the recognizer no longer separates machine execution from criteria in the needed sense.
3. **"Those passages support a natural reconstruction"** — THIN — The cited Naur themes make the reconstruction plausible, but they do not uniquely select the bridge premise. The note later names world knowledge and intrinsic mental possession as live alternatives, so the reconstruction remains conditional.
4. **"The supplied package did not convey enough program-specific understanding to that successor group."** — THIN — The compiler case supports a transfer gap, but the stated evidence also permits weaker readings: design disagreement, different priorities, or original-team authority rather than absence of program theory in the successor group.
5. **"It gives three tests for any claim that an interpreter-plus-artifact composite holds a program's theory"** — HOLDS — Program-specific acquisition and dispositional reliability follow from the note's reconstruction of theory possession. The premise-supply test is less directly derived from Naur, but it is clearly marked as a recovery test imported from a linked note.

## For the human

Look first at the recognizer countermodel: the note most needs a sharper concretization of why a non-programming learned classifier is enough to break the bridge from unformulable modification criteria to human-only theory possession.
