# Friction check: Addressability grain, not compression ratio, sets a matched selective-read floor

**Note:** kb/notes/addressability-grain-not-compression-ratio-decides-whether-a.md
**Central claim (one sentence):** For a known question whose answer is explicit in one discriminately retrievable unit on both sides, a summary lowers the selective-retrieval floor only when its addressable unit is finer than the source unit, so whole-artifact compression ratios cannot decide that comparison.

## Filter
**Verdict:** SURVIVES

The claimed properties can coexist because the note limits the rule to recoverable cache content, a fixed question and reliability requirement, one answer-bearing unit per side, and retrieval-floor contribution rather than total summary value.

## Signal — thinnest joints
1. **“The selected unit sets the retrieval floor for reaching that material. A summary cannot lower the floor unless its unit is smaller than the source unit.”** — UNSUPPORTED — The note defines grain as the smallest independently retrievable unit but never defines the magnitude by which two unlike units are “smaller.” A semantically finer unit can contain more tokens or require more reading time than a coarser but compressed unit, so finer scope alone does not yet establish a lower cost floor.
2. **“Without that layer, the same routing question requires opening enough of each note to judge its relevance. The description therefore exposes a finer unit for the matched routing question.”** — UNSUPPORTED — The example retrieves one description per candidate and inspects material from each candidate note, so the routing answer appears to fan out across several units rather than satisfy the stated one-answer-bearing-unit-per-side condition. The note does not concretize a single matched unit comparison that makes this its helping witness.
3. **“Commonplace, the system this note is written inside, supplies an existential witness for each outcome. The pair shows that the grain test can discriminate within one repository.”** — THIN — The two cases show plausible opposite rankings, but they concern different questions, artifacts, keys, and retrieval procedures. Their coexistence does not by itself show that the grain test, rather than those other differences, produced the outcomes; the text partly concedes this without supplying a within-case counterfactual.
4. **“Once both sides reach their floors, further specificity changes neither cost.”** — THIN — Reaching a minimum structural retrieval unit fixes the material returned only under the ideal discriminating-key assumption. Greater specificity can still change hit multiplicity, disambiguation work, query construction, or inspection within the returned unit, so the unchanged quantity must be narrowed to selected-unit extent rather than unqualified cost.
5. **“A ratio between two totals says how much smaller the complete summary is than the complete source. It does not say how much of either artifact a query retrieves.”** — HOLDS — Whole-artifact totals do not determine query-to-unit mappings or selected-unit sizes, so the same compression ratio is compatible with different selective-retrieval floors.

## For the human
Define the ordering and cost measure that makes one heterogeneous addressable unit “finer” and therefore cheaper, then rebuild the description example as an actual one-unit matched comparison.
