# Friction check: Instantiation alone cannot model agent learning across sessions

**Note:** kb/notes/instantiation-alone-cannot-model-agent-learning-across-sessions.md
**Central claim (one sentence):** The class/instance analogy models how a durable agent definition starts sessions, but cross-session learning requires a separate evidence-responsive retained update relation that changes later definitions and may revise reusable-content placement.

## Filter
**Verdict:** SURVIVES

The note commits to one coherent position: instantiation can explain session startup while still being insufficient as a complete model of learning, because learning across sessions needs a durable path from session evidence back into what later sessions inherit.

## Signal — thinnest joints
1. **“Agent harnesses often lack an equally enforced crossing, because a session can edit a skill file using the same tools it uses for ordinary work. In those systems, permissions, review authority, and versioned retention have to establish the process boundary.”** — UNSUPPORTED — The note shows that some harnesses blur ordinary work and definition change, but it does not establish why those three governance devices are necessary rather than just possible ways to rebuild the missing boundary.
2. **“It does, however, provide evidence about what the starting definition omitted and whether later sessions should retrieve, preload, codify, or continue to derive the material locally.”** — THIN — In-session usefulness can suggest a reusable omission, but the note does not show how to distinguish that from a one-off task need or transient convenience.
3. **“Marked crossings still give us vocabulary for the second relation.”** — THIN — The examples show several systems treat definition change specially, but the note only partly bridges from those heterogeneous mechanisms to the stronger claim that the analogy already supplies the right conceptual vocabulary for agent learning.
4. **“This supports the distinction between starting a fresh session from an unchanged definition and preparing a changed definition for later sessions.”** — THIN — The Machine Studying example is explicitly bounded, so it supports practical importance in one setting, but it does not by itself show that the note's general startup/update distinction is the operative explanation.

## For the human
Look first at the jump from “ordinary tools can edit durable artifacts” to the specific governance boundary the note says must follow, because that is the most load-bearing concretization the note still leaves underspecified.
