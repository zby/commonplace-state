# Friction check: Addressability grain, not compression ratio, sets a matched selective-read floor

**Note:** `kb/notes/addressability-grain-sets-a-matched-selective-read-floor.md`
**Central claim (one sentence):** For recoverable content and a matched selective question where each path can expose one explicit answer-bearing unit, the lower raw selective-read floor is whichever path retrieves the smaller addressed unit, so summary compression helps only when the summary path is finer at that unit level rather than merely smaller as a whole artifact.

## Filter
**Verdict:** SURVIVES

The claim resolves to one coherent conditional rule at one stated scope: matched one-unit selective reads over recoverable content in one declared read-volume currency. Its exclusions for sufficiency, discovery, freshness, overhead, and multi-unit reconstruction narrow the claim instead of splitting it into incompatible commitments.

## Signal — thinnest joints
1. **"For a candidate whose path and title do not settle a routing question ... without that layer, the reader must open enough of the same note to judge relevance. ... the description therefore exposes a finer unit."** — UNSUPPORTED — The note stipulates that path and title are insufficient, but it does not show why no other already-exposed key or snippet path could answer the same routing question at comparable grain in the compared setup.
2. **"In a 2026-08-23 Commonplace snapshot ... the source path therefore had the lower byte-volume floor."** — UNSUPPORTED — The byte counts show one retrieved output shorter than another, but the note does not demonstrate inside itself that both compared outputs are equally matched, reliability-compliant, single answer-bearing units rather than tool-shaped excerpts.
3. **"The pair shows that either side can win."** — THIN — The two Commonplace cases do show opposite orderings, but they do not isolate addressability grain as the deciding factor rather than one feature bundled with other task differences.
4. **"A coarser summary can still win overall when it consolidates several source units, disambiguates many hits, supplies unknown vocabulary, or avoids interpretation and verification work."** — HOLDS — This follows from the note's explicit separation between the one-unit raw-volume test and the rest of the cost ledger.
5. **"The whole-artifact compression ratio alone cannot determine this comparison unless each whole artifact is itself the selected unit."** — HOLDS — Once the comparison is fixed at one addressed unit per path, total artifact size stops determining what must actually be loaded for the matched question.

## For the human
Look first at the two Commonplace witness cases, especially the claimed matched units and stopping condition on each path; that is where the note most needs the author's missing concretization.
