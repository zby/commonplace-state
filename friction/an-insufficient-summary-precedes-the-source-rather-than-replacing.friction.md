# Friction check: An insufficient summary precedes the source rather than replacing it

**Note:** kb/notes/an-insufficient-summary-precedes-the-source-rather-than-replacing.md
**Central claim (one sentence):** For a fixed question and required reliability with no alternative authoritative evidence route, an insufficient summary cannot replace the source path, and its read-cost value is the source-path work it removes minus the cost of consuming it.

## Filter
**Verdict:** SURVIVES

The claim asks insufficiency, reliability compliance, retained source-path work, and possible partial savings to hold together. They can coexist: needing some source-path work prevents full substitution without requiring every source-path operation to remain unchanged.

## Signal — thinnest joints
1. **“A materialized or frontloaded answer earns credit only for derivation it prevents. If the full derivation still runs unchanged, the answer is pure addition regardless of its size.”** — UNSUPPORTED — An unchanged derivation does not show that every other kind of fallback work is unchanged. The note earlier allows credit for removed discovery, selection, interpretation, or verification work, any of which a materialized answer could reduce even when derivation still occurs.
2. **“If the summary is insufficient, every reliability-compliant route retains source-path work.”** — THIN — Insufficiency establishes this only for a route that must still answer the question or license the action. A reliability-compliant route can abstain or defer without using the source path; the later scope narrows the claim to a “reliability-compliant answer,” but the load-bearing statement here does not.
3. **“The resulting ledger is: read-cost value = fallback work removed − summary consumption cost.”** — THIN — The route comparison yields this exact ledger only if those two terms exhaust every differential read cost. The note does not assign coverage assessment, route switching, or integration overhead explicitly to either source-path work or summary consumption cost.
4. **“Using a whole-artifact compression ratio as a proxy for read-cost savings assumes that one artifact substitutes for the other.”** — THIN — An empirically calibrated ratio could proxy partial savings without assuming substitution. What the surrounding argument establishes is the narrower point that compression ratio alone does not identify how much fallback work was removed.
5. **“The failures also require different repairs.”** — THIN — Independence of grain and sufficiency does not make their repairs categorically different: direct source routing or a narrower declared use can avoid either failure, and addressability can change verification work. The listed remedies support “often suggest different repairs,” not “require.”

## For the human
Look first at the “pure addition” consequence: reconcile it with the note's own rule that an answer may remove non-derivation fallback work even when the full derivation still runs.
