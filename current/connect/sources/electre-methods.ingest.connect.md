The useful KB question is how to judge the routing remedy against the incumbent without confusing a rejected directional claim, ineligible remedy, and adoption decision. ## Connections Found

- [Yu on nondominated solutions](../../../../../sources/yu-cone-convexity-and-nondominated-solutions.ingest.md) — **compares-with**: A dominance rule screens a feasible set; an ELECTRE Iv veto blocks one directional claim. Neither by itself selects a winner, and ineligibility is separate. Use Yu's abstract for this distinction, not for theorems or implementation details it does not contain.
- [Ordinal Regression Revisited](../../../../../sources/greco-ordinal-regression-revisited.ingest.md) — **compares-with**: Ask whether neither direction passes *under one fixed rule* or whether no weak preference holds *across all compatible additive models*. The answer directs the maintainer to inspect criterion-specific support and opposition in the first case, or which admitted trade-offs reverse the ordering in the second.
- [Decision Support by Interval SMART/SWING](../../../../../sources/mustajoki-interval-smart-swing.ingest.md) — **compares-with**: Interval ratios bound how gains offset losses in an additive model. ELECTRE Iv weights count support, and a vetoed loss cannot be offset by more votes. Elicit an exchange-rate bound only if the decision permits exchange on that criterion.
- [Maintainability-oracle designs](../../../../../theory/brainstorming-maintainability-oracles-for-agentic-development.md) — **compares-with**: A failed compatibility check in the note's veto stack can make a candidate ineligible before ranking. An ELECTRE Iv veto can leave an eligible candidate incomparable with one rival while it still outranks another. Put non-negotiable commitments in eligibility checks rather than assuming a relative veto enforces them.
- [A better-factory claim compares operative states under an antecedent assessment relation](../../../../../theory/a-better-factory-claim-compares-operative-states.md) — **compares-with**: Both can block an otherwise favorable comparison on a declared regression. The factory rule tests an adopted successor against the predecessor's declared capabilities plus a named gain; ELECTRE Iv tests both directions and allows several weighted criteria to supply support. Failing the former does not establish a reverse preference either.
- [Meta-Harness](../../../../../agent-memory-systems/reviews/meta-harness.md) — **compares-with**: The historical text-classification loop keeps an accuracy/context-length Pareto frontier after evaluation rather than choosing a single winner by weighted score. This is a concrete contrast for KB retrieval changes: dominance can leave the quality/cost trade-off on the frontier, while a declared pairwise veto can block one direction on a sufficiently large regression. The review does not report use of ELECTRE.

## Synthesis Opportunities

[A local comparison can leave candidates unordered](../../../../../theory/selection-based-learning-needs-only-a-local-comparison.md), and [a bounded trial is a different alternative from permanent adoption](../../../../../theory/reversibility-can-favor-a-change-by-limiting-future-loss.md). Together with the ingest, these suggest a worked routing comparison that reports three separate results: whether each remedy is eligible, which directional claims pass, and what to do when neither passes. A reversible trial can be a third alternative with its own checked consequences, not a reason to record an incomparable pair as a win. If used repeatedly, a separate selection policy must address possible cycles in the comparison relation.
