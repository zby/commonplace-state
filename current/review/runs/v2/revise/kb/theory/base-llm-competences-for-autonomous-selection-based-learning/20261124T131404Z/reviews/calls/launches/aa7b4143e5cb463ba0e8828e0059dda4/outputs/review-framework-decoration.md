# Review

## Summary

The note has two list structures.

**Numbered list of three competences.** This list does load-bearing work. Later passages refer to the competences by number: criterion revision "reduces to competences 2 and 3", and the open question asks how harness interfaces affect "competences 2 and 3". The claim that the competences "fail independently and sit at different capability thresholds" needs them as separate units. It supports the bootstrap decision about which competence binds and the open question about which binds first. Each item also links to a note that develops that competence. One sentence could not keep these distinctions or the inferences that depend on them.

**Bullet list of harness categories.** This list is mostly illustrative. Its category labels are not used later, as the finding explains. The examples it lists do support the offloading claim and are reused later. This is a minor decoration risk, not a failure.

The note has no tables, notation or equations.
